AI Trading Signal - iPhone Web-App MVP

Enthalten: index.html und manifest.webmanifest.

WICHTIG: Noch keine Live-Marktdaten, keine echten Push-Nachrichten, keine KI und keine automatischen Trades. Die App wertet manuell eingegebene, gleichmaessig zeitlich beabstandete Schlusskurse aus und berechnet EMA9, EMA21, RSI14 und eine beispielhafte Positionsgroesse.

Installation ohne Mac:
1. Kostenloses GitHub-Konto verwenden.
2. Auf github.com/new ein oeffentliches Repository z.B. ai-trading-signal erstellen.
3. Dateien index.html und manifest.webmanifest ueber Add file > Upload files hochladen (auf iPhone ggf. Desktopwebsite anfordern). Die Dateien muessen im Hauptverzeichnis liegen.
4. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Warten, bis GitHub Pages die Adresse https://BENUTZERNAME.github.io/ai-trading-signal/ anzeigt.
6. Diese Adresse in Safari auf dem iPhone oeffnen, Teilen > Zum Home-Bildschirm.

Achtung: Ein oeffentliches Repository ist fuer jeden lesbar. Keine API-Schluessel, Passwoerter oder persoenlichen Finanzdaten in die Dateien eintragen.

Bei GitHub Pages wird die Seite ueber HTTPS bereitgestellt. Ein GitHub-Konto und Internetzugang sind zur Bereitstellung erforderlich. Fuer echte Pushs bei geschlossener App waeren weitere Dienste und Entwicklung notwendig.
